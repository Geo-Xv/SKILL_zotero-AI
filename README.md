# SKILL_zotero-AI

> **更巧妙地让 AI 与 Zotero 协同合作：帮助您读取文献，并针对待阅读文献中与您工作相关的核心内容进行精准批注与高亮显示。**

`SKILL_zotero-AI` 是一个专为学术研究与论文精读设计的 AI Agent 技能定义。它指导 AI 结合用户的具体研究问题，通过 Zotero 本地 API 接口，直接在 PDF 原文的公式、算法、段落和实验旁生成或改写**原生高亮与通俗中文批注**。

---

## ✨ 核心亮点

* **📄 原生 PDF 批注交付，零额外噪音**
  * 默认仅交付 Zotero PDF 原生高亮（Highlight）与中文评论（Comment）。
  * **不创建**额外的子笔记、阅读导航或独立阅读文档，**不简单复读/翻译**原文，保持阅读界面干净纯粹。

* **🎯 拒绝“正确的废话”，强制具体化讲解**
  * 严禁使用“该公式很重要”“可用于优化模型”等通用套话。
  * **公式拆解**：沿用原文符号，明确指出已知量与决策变量，讲清各种运算的作用与物理含义。
  * **方法与算法**：按“输入 $\rightarrow$ 核心步骤与中间结果传递 $\rightarrow$ 输出”讲清完整逻辑链条。
  * **结合你的研究问题**：将论文中的方法具体映射到你的模型变量、约束、目标函数或实验设计中（如交通运输、船—无人机协同配送、运筹优化等）。

* **🔍 高精度定位与视觉核验**
  * 当 PDF 提取中的上下标、求和范围或不等号等存疑时，自动渲染对应页面进行视觉核验。
  * 精准区分 PDF 物理页序（`pageIndex`）与印刷页码，构造行级高亮矩形（`rects`），避免大块覆盖无关内容。
  * 支持语义化颜色编码（黄色：基础解释；蓝色：应用；橙色：前提条件）。

* **🛡️ 安全、无感、幂等的后台接口操作**
  * **零 UI 自动化**：全程通过 Zotero 本地 HTTP API 操作，不接管鼠标、键盘或切换窗口。
  * **数据安全**：不直接修改 Zotero SQLite 数据库，不替换原 PDF 文件，不擅自删除已有笔记。
  * **幂等去重与写后核验**：写入前比对已有批注防重；写入后逐一校验，确保每一条批注真实落盘。

## 💡 批注讲解对比

本 Skill 对批注的“具体程度”有严格的校验标准——**如果一段批注换到另一篇论文还能原封不动使用，则视为不合格。**

| 批注类型 | 示例内容 |
| :--- | :--- |
| ❌ **传统 AI 泛泛而谈** | “作者在此引入了辅助变量，把欧氏距离改写成二阶锥约束，这种方法很巧妙，适用于你的船—无人机协同配送模型。” |
| ✅ **本 Skill 精准批注** | “这里原先要把几段距离相加后求最小。作者给每段距离增加一个变量 $t_i$，要求 $t_i$ 不小于该段真实距离，再最小化这些 $t_i$ 的和。例如，某段距离是 $5$，$t_i$ 可以取 $6$，但取 $5$ 会让目标更小，所以在这里会降到 $5$。这样就把目标中的根号移到了约束里。放到你的问题中，可以用同样思路表达起飞点到海岛的距离；如果新变量还参与其他约束，就要再看能不能这样降低。” |

## 🛠️ 环境要求与配置

1. **Zotero 客户端**
   * 需开启本地 API 服务（默认监听地址为 `http://127.0.0.1:23119/api`，已在 Windows Zotero 10.0.6 验证）。
2. **AI Agent 环境**
   * 支持加载 `SKILL.md` 的 AI 工具（如 Claude Code、Cursor、Cline、Windsurf 等）。

## 🚀 使用指南

### 1. 配置 Skill
将仓库中的 `skill.md` 复制或载入你的 Agent 技能目录中：
```bash
# 以 Claude Code 为例
mkdir -p ~/.claude/skills/zotero-useful-annotations
cp skill.md ~/.claude/skills/zotero-useful-annotations/SKILL.md
```

### 2. 对话触发
在对话中告诉 AI 你要精读的论文名称以及你当前关注的研究问题：
> “帮我读一下 Zotero 里的《*论文名称*》，结合我目前正在做的**船—无人机协同配送起降点优化**问题，把里面有用的数学模型和求解算法用能听懂的话批注在 PDF 上。”

### 3. 确认本地授权
* AI 计算好批注与坐标后，会发起请求，Zotero 客户端将弹出授权窗口。
* **在 Zotero 中手动点击允许授权**后，AI 即可完成批量写入与核验。
